# ZZFilterPlugin v20

## 目标
- 系统版本筛选改为严格模式：设置了最低/最高版本后，商品必须能解析出真实的 iOS/系统版本且版本落在范围内，未知版本不再作为“命中”展示。
- “系统版本筛选结果”页面的商品名称直接追加真实版本，例如：`iPhone 15 Pro Max 256G 黑色钛金属 · iOS 26.1`。
- 结果页继续保留“复制 / 打开”操作；优先使用列表原始 `jumpUrl/detailUrl/shareUrl` 等真实链接，不凭空生成链接。
- 结果缓存只把能解析出真实系统版本的记录计入“已缓存版本商品”。

## v19 问题修复
- v19 的结果页可能把历史/未知版本缓存当作有效结果，导致 20 条结果全部显示为不准确的版本。
- v20 不再把 `version=1.0.0` 等通用字段当作系统版本。
- 设置了版本范围时，未知系统版本不会被放进最终筛选结果。

## 稳定性
- 保持网络 + 商品详情缓存路线。
- 不恢复全局 Runtime 扫描，也不加入高频 UI 扫描。
- 详情预取仍限制数量与并发，避免此前出现的高 CPU、发热和 watchdog 问题。

## 构建卫生
- 主控制器 `@implementation/@end` 结构保持完整。
- helper controller 的 `@interface/@implementation` 独立放置。
- 修改后使用 `verify-source-structure.py` 做结构检查，再交给 GitHub Actions 编译。
